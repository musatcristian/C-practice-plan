1 - Understand source files, object files (.o), header files, symbol resolution and linking. Learn the difference between compiling a translation unit and linking multiple object files into an executable

[GNU C Ref 29. Compilation](https://www.gnu.org/software/c-intro-and-ref/manual/html_node/Compilation.html)

2 - Focus on targets, prerequisites, recipes and variables. Understand how Make decides which files need rebuilding.

[GNU Make 2. Intro](https://www.gnu.org/software/make/manual/html_node/Introduction.html)

3 - Read the GDB manual, focusing on breakpoints, stepping, examining data and the call stack.
Also learn watchpoints, which stop execution when a watched expression changes.

[GDB intro](https://sourceware.org/gdb/current/onlinedocs/gdb.html)
