Week 2 completion criteria
You should be able to:
- Identify common invalid memory operations.
- Explain the difference between a memory leak and a dangling pointer.
- Explain why signed overflow is not guaranteed to wrap.
- Use AddressSanitizer and UndefinedBehaviorSanitizer.
- Reproduce a bug and explain its root cause.
- Use GDB to inspect variables and trace program execution.
