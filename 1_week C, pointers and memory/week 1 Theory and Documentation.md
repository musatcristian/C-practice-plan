## 1 - C language basics
###### *Time: 60–90 min*
Read the introductory sections of the GNU C Language Manual. Focus on variables, types, expressions, functions, control flow, arrays and pointers.  
Skip advanced material for now.

> [GNU C Ref Intro](https://www.gnu.org/software/c-intro-and-ref/manual/c-intro-and-ref.html)

## 2 - Pointers and arrays
###### *Time: 60–90 min*
Use Beej's Guide to C Programming as a second explanation. Understand addresses, &, *, pointer arithmetic, array indexing and the relationship between arrays and pointers.  
They are related, but not identical.

> [Beej Guide C](https://beej.us/guide/bgc)

## 3 - Structures and object lifetime
###### *Time: 45–60 min*
Use cppreference: C language to look up structures, scope, storage duration and object lifetime.  
Learn the difference between a variable's scope, its lifetime and the memory occupied by its object.

> [C_Cpp Ref intro](https://en.cppreference.com/c/language)
